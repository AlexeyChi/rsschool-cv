## Code Examples

___5 kyu KATA from___ [CODEWARS](https://www.codewars.com/kata/52597aa56021e91c93000cb0 "Moving Zeros To The End") Moving Zeros To The End

Write an algorithm that takes an array and moves all of the zeros to the end, preserving the order of the other elements.

  `moveZeros([false,1,0,1,2,0,1,3,"a"]) // returns[false,1,1,2,1,3,"a",0,0]`

```javascript
function moveZeros(arr) {
    const notNull = arr.filter((i) => i !== 0);
    const nulls = arr.filter((i) => i === 0);
    return [...notNull, ...nulls];
}
```
